## 1. 模块目标

一句话：把用户一年在麦当劳的下单时间，鉴定成一种打工人作息人格，出一张值得截图发群的卡片。

输入是麦当劳官方 MCP 的真实历史订单，输出是一张「麦门作息鉴定卡」：一个大称号、一张时段分布图、三个关键数字、一句扎心判词。全程一行命令，无 Token 也能用内置样例跑。

它回答的问题没人回答过：你吃了什么不重要，你**什么时候**吃的才说明你是谁。

## 3. 边界（不做什么）

- 不提供 Web 服务、不提供微信小程序（比赛只认 GitHub 仓库）。
- v1 不做复合人格、积分彩蛋、营养维度（PRD 已列为可砍项）。
- 文案不做健康评价、不做饮食建议、不出现「应不应该吃」句式；夜宵人格写生活状态不写身体后果。
- 卡片与文案零出现其他品牌。
- 不触碰优惠券维度人格（规避「利用规则漏洞」红线）。

## 5. 口径修订（对 PRD v1.0 的两处勘误）

1. **T9 规律度单位统一为「分钟」**：PRD 原文「下单小时的标准差」与阈值「< 75 分钟」单位不一致。修订：T9 = 下单时刻（分钟数）的离散度量，跨零点时段的处理方式在设计文档定死。
2. **夜宵时段 21-5 跨零点**：T1 时段划分与 T4 夜宵率涉及跨零点窗口，直接标准差会失真（23:00 与 01:00 被算作相距 22 小时）。修订：设计文档必须明确环形时间或窗口拆分方案。
